MGP24 Master Editor

Open a project in Setup first.

Port bike audio from another game

Point this at the other game's extracted Audio folder (the one containing Bindings, Events, Banks and WwiseAudio). It copies the bank, events, bank asset and BikeAudio asset, converted to this game's layout, and adds missing Init.bnk objects. Nothing is written until Port; files are staged like other edits (Save to apply). Afterwards use Replace on a rider's audio row and paste the new BikeAudio path shown below.

Bike sounds from MotoGP 26 (newer Wwise)

Point this at a folder with MotoGP 26 bike banks (e.g. MotoGP_Ducati.bnk, exported raw with FModel). Each is matched to this game's bank of the same name: the game's bank stays (events, mix, RPM curves) and the newer game's sounds, engine models (converted to this game's REV format) and engine settings are swapped in. Sounds only the newer game has are not used. Files are staged like other edits (Save, then Pack mod).

HUD skin

Copy the look (colours, fonts, shadows, images) of another game's widget onto the game's own widget, keeping the game's layout and logic. Put the other game's extracted widget (.uasset + .uexp, same file name) in a folder, pick the game's widget below, and compare. Only values the target can take as they are get copied; items marked "needs import" use a font or image the game's widget doesn't reference yet.

Import whole files

Copies the other game's widget files into your mod folder, replacing the game's own, exactly like swapping the files by hand. Keep the folders from Content/ down, or use the original file names: they are placed where the game's file of that name lives. Staged until you Save. Penalty/warning widgets are marked: they depend on game logic and can show wrongly when taken from another game. Font files (ui/Fonts) are never imported: another game's font assets crash this one.

Skin only (keep the game's own widget)

e.g. hide PenaltyTime in RaceHud_BP
needs the FF_TTSupermolotNeue-* font files in Content/assets/ui/Fonts

Font swap

Replaces a game font with a real font file (.ttf / .otf / .ufont): it is written as <font>.ufont, which the game's own font asset reads (how the big MotoGPText-Display text already works). Another game's font asset of the same name in your mod is replaced by the game's own.

Replacement sheet

Every rider, team, bike and track of the base game. Type who/what each becomes in your mod (and a note); it autosaves to _mgp_replacement_sheet.json in the mod folder (not packed). "DB changes" shows what your mod's database already differs on.

Localization (.locres)

Edit the game's texts (menus, names, messages). Pick a file, search, change a text and press Enter or click away; it is staged like other edits (Save writes it to the mod folder). Only existing entries can be edited. The file's own paks are never touched.

Browse game files

Everything in the paks and your mod folder. Click a folder to open it; search looks inside the current folder and below. Edit opens an asset in UAssetGUI (a copy is staged first), Clone copies a data asset under a new name in the same folder, Extract copies the files straight into your mod folder (no Save needed).

Pick a table.

Check bindings

Finds every binding row that points at an asset that does not exist, and suggests the existing asset with a different trailing number. For one table it also shows teams whose riders point at different assets.

Clone audit

Dry-runs a copy of every distinct asset (writes nothing) and groups what would fail and why. Useful to find entries clone can't handle yet; it can take a while on all tables.

Match riders to their team

Compares each rider's row with their team's row in the matching …_BikeTeams table (e.g. WinterTest: the team row holds the right carbon number). Only riders that differ are listed. Some tables may differ on purpose (e.g. a rider's own bike), so check before fixing.

Setup

Changes are held until you press Save (Ctrl+S). Exit asks what to do with unsaved changes. Folders are paths on the computer running this editor. Settings are remembered in mgp_config.json.
