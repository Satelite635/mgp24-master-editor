# Changelog (versions shipped as zips; bump `VERSION` in webui.py AND `HV` in webui.html)

- **v100** Setup keeps mod folder, Paks folder, patch-pak tick and game exe per game (`gk()`: GP24 keeps the old config keys, GP25 uses `*_gp25`); switching the Game picker fills that game's paths. A config last used for GP25 is migrated once (its shared paths become GP25's; GP24's must be entered again).
- **v99** MotoGP 25 Riders & bindings: row targets with numbered FNames (name + number, e.g. `T_Suit_12` stored as `T_Suit` #13) are read and written like FName does (`split_fname`); before, they raised 'numbered FName ... not supported' and the view stayed empty. A table whose row cannot be read no longer hides the others.
- **v98** start.bat installs `blake3` once if missing (like pycryptodome); a failed install is not fatal (pure-Python fallback).
- **v97** MotoGP 25 Pack mod also takes `.ubulk` (next to its .uasset): written as a BulkData chunk (type 2) with the package's id, as in Faizal's Gresinisepang_P (UE-made, Oodle) container. `.m.ubulk`/`.uptnl` still refused. BLAKE3 uses the `blake3` pip module when installed (pure Python is ~1 MB/s).
- **v96** MotoGP 25 **Pack mod** writes zen assets as `<name>_P.utoc/.ucas` + `.pak` (`mgp_iostore.write_container`: uncompressed, unencrypted, no perfect hash, container header v4, BLAKE3 chunk hashes - retoc's layout; non-assets go in the .pak, else retoc's empty v11 .pak). Checked: rewriting Faizal's retoc mod (2026_Aero26_Allbike_Model_P) gives a byte-identical .utoc and .ucas (`test_zen.py`). Only .uasset (no .ubulk) so far.
- **v95** MotoGP 25: Riders & bindings, Check and Browse shown. New `mgp_iostore.py` (.utoc/.ucas reader, TOC v8, Oodle blocks, directory index; CityHash64) and `mgp_zen.py` (zen package header + name batch rebuild; `ZenBindingTable` for IgnitionDataAssetTableRow tables). `PakSet` also loads `*.utoc`. Offline: the 3 GP25 bike tables parse, match FModel's JSON, rebuild byte-identical, repoint + re-parse OK; name hashes and package ids match the game's. Not yet for GP25: cloning/copying assets, riding style, and packing assets (needs a .utoc/.ucas writer) - packing skips them with a note.
- **v94** Oodle: also loads FModel's `oodle-data-shared.dll` (Faizal's FModel only has that one).
- **v93** Oodle-compressed paks (GP25): `mgp_oodle.py` loads `oo2core_*_win64.dll` with ctypes (searched next to the tool/exe, below the game folder, FModel folders, or env MGP_OODLE_DLL). Not testable offline (Linux, no DLL). GP25: after Open the tool went to the hidden Riders tab (blank page); it now opens Localization.
- **v92** Setup: **Game** picker (MotoGP 24 / MotoGP 25). GP25 (UE5.5, IoStore) is a test mode: only Localization and Database are shown, since `.locres`/`db.sqlite3` stay in its legacy .pak; its .uassets (bindings etc.) are zen packages in .utoc/.ucas and are not read yet. Paths use `motogp25/`, packing skips the crash check, each game keeps its own saved AES key (GP25 default built in). Untested in game: whether GP25 loads a plain v8 `_P.pak` without .utoc/.ucas.
- **v91** Font swap Browse: the file dialog filters fonts (.ttf/.otf/.ufont, kind "font") instead of programs (.exe).
- **v90** Projector table column "Number texture": shows the rider's number texture name for projectors that have a texture (the file's own `47` in the tooltip); "-" = no texture in the file.
- **v89** Projector section shows the entry's number: `DT_Numbers_*` row → `ProjectorNumbers/customization_data/<Rider>_Number` → Texture2D package(s) it imports (`_number_textures`). Column renamed "Texture in file" (the 47 placeholder).
- **v88** Projector lookup uses the real link first: binding tables `DT_NumbersProjectors_BikeTeams` / `DT_NumbersProjectorsCustom_BikeTeams` are keyed by TEAM; riders resolve via `Pilots.Teams_Key` in the game DB (`_projector_tables`). Official/teams list the non-custom file first, custom the custom one. Reference scan and chassis/variant guess remain as fallbacks. Note: a team's projector file is shared by all its riders.
- **v87** Projector lookup fallback: any `*projector*_NNN` in `<chassisCCC>/customization_data` whose number equals the bike variant (compared as int), official riders get `projectorCCC_VVV` first, custom `ProjectorCustomCCC_VVV`; error lines include the bike path. Real naming (Faizal, Oct 21): chassis103/customization_data/projector103_004 (official, Yamaha) and ProjectorCustom103_004 (custom); bikes don't reference them (only HelmetProjectorDataSource was found).
- **v86** HUD skin: **Font swap** (`fontswap.py`, `/api/fontswap*`): pick a .ttf/.otf/.ufont, tick game FontFaces, it writes `<face>.ufont` (staged) and puts the game's own FontFace asset back where the mod had another one (SBK's, pointing to projects/sbk1). Reason: see FONTS.md "Why small fonts reverted".
